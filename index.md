# Kael Coach – Privacy Policy

Kael Coach is a personal, single-user application. It is used only by its developer,
on the developer's own computer, to read the developer's own health data.

**Data accessed.** With the user's consent (read-only scopes), the app reads sleep,
heart rate, heart rate variability, resting heart rate, steps, exercise, weight,
body fat and oxygen saturation from the Google Health API.

**Use.** The data is used only to suggest workouts adapted to the user's
recovery state.

**Storage.** Data and access tokens are stored locally on the user's own computer.
They are not sent to any server operated by the developer, and are not sold,
shared, or disclosed to any third party.

**Retention and deletion.** The user can delete the local data at any time and can
revoke the app's access from the Google Account permissions page
(https://myaccount.google.com/permissions).

**Google API Services User Data Policy.** The use of information received from
Google APIs adheres to the Google API Services User Data Policy, including the
Limited Use requirements.

**Contact.** Questions: open an issue on this repository.
